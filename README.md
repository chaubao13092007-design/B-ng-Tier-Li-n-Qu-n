# Bảng Tier Liên Quân

Tier list tướng Liên Quân Mobile theo từng đường, chấm điểm từ số liệu ĐTDV, giải RoV Pro League, tier list rank cộng đồng và báo game.

**Xem web:** https://tierlq.github.io/

- `index.html` — trang chính
- `assets/data.js` — số liệu, danh sách tướng và cách chấm điểm
- `assets/app.js` — giao diện
- `p/`, `s/` — ảnh chân dung và ảnh bìa tướng

Hình tướng thuộc bản quyền Garena / TiMi Studio, lấy từ kho ảnh cộng đồng [AoV-IndeX/avix-assets](https://github.com/AoV-IndeX/avix-assets). Bảng mang tính tham khảo, phi thương mại.
